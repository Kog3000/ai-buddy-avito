# Спецификация: права и данные

### Requirement: Недоступные сведения не раскрываются
- Материалы с `audience=mentor|lead` и материалы чужих команд не попадают в поиск, ответы, контекст LLM и страницы.
- Обращение к недоступному материалу отвечает «не найдено» (404), а не «нет прав», чтобы не раскрывать факт существования.
- Тесты: `test_kb_restricted_topics_hidden_from_intern`, `test_kb_team_scoped_topics`,
  `test_intern_cannot_see_mentor_material_in_chat`, `test_llm_answer_uses_context`

### Requirement: Недоступные операции не выполняются
- Стажёр не может согласовывать заявки, отвечать за наставника, публиковать в FAQ, переключать флаги.
- Согласовать заявку может только назначенный согласующий; цель стажёра — только его руководитель.
- Данные стажёра видят он сам, его наставник и руководитель.
- Тесты: `test_access_lifecycle_with_owner_approval`, `test_goals`, `test_mentor_sees_only_own_interns`,
  `test_intern_cannot_open_staff_pages`

### Requirement: Защита веб-интерфейса
- Сессионная cookie `HttpOnly`, `SameSite=Lax`; все изменяющие запросы требуют `X-CSRF-Token`.
- Редирект после входа — только на относительные пути (защита от open redirect).
- Markdown рендерится с экранированием HTML.
- Тесты: `test_csrf_enforced`, `test_login_logout`, `test_markdown_render_is_safe`

### Requirement: Вне области прототипа
- Больничные и иные медицинские данные — агент перенаправляет к HR, ничего не сохраняет (`test_sick_is_redirected`).
- Финансовые операции и выплаты не обрабатываются.
- Все данные синтетические; материалы помечены как тестовые и не выдаются за регламенты Авито.

### Requirement: Секреты
- Ключ LLM задаётся только переменной окружения `LLM_API_KEY`; в репозитории — `.env.example` без секретов.
- В LLM передаются только: имя, роль, команда, этап адаптации, наставник/руководитель, следующие шаги и найденные материалы.
